Данный бот предназначен для парсинга сайта для фриланса - fl.ru.

Работать с ним очень просто: достаточно заменить в файле config.py api ключ бота, ссылку на БД на свои, и там же выставить ссылку на каталог, с которого будут парситься данные.

Данные предоставляются в формате:
Название, описание, цена и ссылка
